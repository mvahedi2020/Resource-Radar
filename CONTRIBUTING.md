# Contributing

Keep this repository an independent sample demo. Do not add real customer data, secrets, analytics, authentication, or external service credentials.

Before opening a change, run `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e`, and `npm run build`. Include tests for changes to capacity, allocation, and conflict logic. Keep keyboard focus visible, controls labeled, and the matrix usable on narrow screens.

Product claims must remain truthful. Label proposed targets as targets and sample data as sample data.
