# Sprint backlog

- Weekly capacity matrix with editable initiative person-days.
- Availability math for time off and non-project commitments.
- Overload, full-capacity, open-capacity, and zero-availability states.
- Baseline/draft comparison, apply, undo, reset, and JSON export.
- Initiative risk summaries, search empty state, storage warning, hash navigation, and responsive layout.
- Unit tests for the planning logic.
